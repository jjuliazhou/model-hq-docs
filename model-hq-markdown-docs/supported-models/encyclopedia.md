| Model Type | Purpose |
|-----|-------|
| Agentic | Complete multi-step tasks and make decisions autonomously to accomplish a goal. |
| Cloud | Run on remote servers over the internet, increasing speed and complex capabilities. |
| Coding | Specificaly designed to write computer code. |
| Embedding | Convert text to lists of numbers (vectors) to compare and search for similar content (semantic search). |
| GGUF | A model format that enables large language models (LLMs) to run on local computers. Highly recommended for Mac users. |
| Instruct | Follow human instructions, including answering questions and completing tasks. |
| ONNX | A general-purpose AI model format that allows models to run across different types of devices as a "common language". |
| Re-ranker | Compares, scores, and reorders a list of documents against query based on similarity and relevance. |
| Speech-to-text | Convert spoken audio to written text. |
| Tool | Custom models that perform a particular task, made smaller and faster (quantized) to run better in agent workflows. |
| Question-answer | Specifically designed to answer questions. |
| Vision | Understand and analyze images. |
